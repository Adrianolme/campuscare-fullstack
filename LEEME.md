# CampusCare con backend y base de datos
- `campuscare-web/` → el sitio (HTML/CSS/JS, PWA). Funciona con la API o en modo local.
- `backend/` → API Node.js + Express + MySQL (ver `backend/README.md`).

Inicio rápido: `cd backend && npm install && copy .env.example .env && npm start` → http://localhost:3000
